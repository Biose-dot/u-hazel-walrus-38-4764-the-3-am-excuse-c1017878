# The 3 AM Excuse

Entry for the [make.fun](https://make.fun) bounty
[The 3 AM Excuse](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878).

One line, under 200 characters, in the voice of a hardware wallet refusing to sign at 3 AM. The wallet's excuse is its own ledger: every 3 AM signature it ever wrote ended in regret and a support ticket, so tonight's page stays blank — no battery, firmware, or cold-storage cliché, just a device that has learned from its owner's worst hour.

> My ledger keeps a page for every 3 AM trade you've made. Every one ends in regret. Tonight's page stays blank.

`main.py` (Python 3, standard library only) copies the committed `entry.txt` to `/output/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
